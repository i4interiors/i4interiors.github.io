i4interiors

Website layouts

Two structural approaches to the i4interiors website. Both share the same brand, typography and photography — what differs is how the content is organised and navigated. Each layout is responsive across mobile, tablet and desktop.

Layout A

One page

A single continuous page. The studio statement, services and portfolio unfold in one uninterrupted scroll.

Option 1

Editorial

Opens on a full-screen interior, then moves in sequence through the studio statement, designer profile, services, portfolio and enquiry.

  • Serif display type with generous white space
  • Anchored menu linking to each section
  • Portfolio presented as a nine-image grid
View Option
Layout B

Multi-page

Dedicated pages behind a persistent navigation bar, with the portfolio given its own gallery.

Option 1

Studio

A cleaner, more architectural treatment, with the portfolio promoted to a dedicated gallery page filterable by room type.

  • Navigation tabs for Home, About, Gallery and Contact
  • Filterable gallery with full-size image viewer
  • Contact page with full studio details
View Option

About these pages. Both layouts work equally well on a phone, a tablet or a computer — the photographs and text rearrange themselves to suit whatever screen they are viewed on. The images are prepared in two sizes so pages stay quick to open on mobile data, and each one is described in words for visitors who use a screen reader.
